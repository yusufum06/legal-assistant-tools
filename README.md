# Legal Assistant Tools

Legal Assistant Tools is an open-source project for simplifying administrative
and legal-document workflows.

The project focuses on small, reusable tools that can help users process,
organize and prepare text-based documents more efficiently.

## Planned features

- Text cleaning and formatting
- Document structure analysis
- Extraction of dates and basic document information
- Anonymization of sensitive information
- Reusable document templates
- Multilingual document support
- Automation of repetitive administrative tasks

## Project status

This project is currently in an early stage of development.
New tools and documentation will be added gradually.

Contributions, suggestions and bug reports are welcome.
